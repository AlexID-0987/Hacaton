Цей застосунок розроблений за допомогою ASP.NET Web API. Він дає можливість отримувати дані у форматі JSON та відображати їх на вебсторінці.
Для зберігання даних використовується база даних, яка працює в оперативній пам’яті. Проект імітує допомогу штучного інтелекту та використовує для цього описані програмні конструкції й алгоритми.
Всередині цього solution є два проекти.
Перший проєкт — безпосередньо ASP.NET Web API, зі звичними для нас папками Controllers та Models. Як представлення використовується HTML-сторінка.
У проєкті реалізовано інверсію залежностей за допомогою інтерфейсів та використано Dependency Injection.
Також для роботи з даними використовується база даних, яка зберігається в пам’яті.
Другий проект — тестовий. Він тестує наш контролер: перевіряє повернення даних, їхню коректність, а також поведінку системи у випадку, коли дані відсутні.
